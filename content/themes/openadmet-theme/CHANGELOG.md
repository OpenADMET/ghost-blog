# Changelog

All notable changes to the OpenADMET Ghost theme are documented here.

## 1.2.0 — 2026-09-29
- Replaced the Abril Fatface heading font with IBM Plex Serif (weights 500 and 700) to match openadmet.github.io.

## 1.1.0 — 2026-08-02
- Removed author byline from single post pages, the homepage hero, and post cards.
- Removed the now-unused `show_author` theme customization setting.

## 1.0.0 — 2026-07-27
- Initial release of the OpenADMET custom theme.
